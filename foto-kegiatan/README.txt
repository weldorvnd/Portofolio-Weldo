# FOLDER DOKUMENTASI FOTO KEGIATAN

Folder ini menyimpan seluruh foto kegiatan & dokumentasi profesional Weldo Ravendra Hendri:
1. Survei & Lapangan BPS (Sensus Ekonomi, door-to-door, validasi kuesioner)
2. Pelatihan & Pemetaan Wilkerstat BPS (GIS, digitasi peta wilayah kerja statistik)
3. Pelatihan Teknis & SKP
4. Proyek IT & Mikrokontroler / IoT
5. Dokumentasi Kampus & Kepemimpinan Organisasi

Semua foto di folder ini terhubung secara otomatis ke website portofolio (`index.html`) pada bagian **Galeri Dokumentasi Kegiatan**.

Untuk menambahkan foto baru:
1. Masukkan file foto (.jpg / .jpeg / .png) ke dalam folder ini.
2. Tambahkan card `<div class="gallery-item" ...>` di `index.html` pada bagian `#galeri` sesuai kategori yang diinginkan.
